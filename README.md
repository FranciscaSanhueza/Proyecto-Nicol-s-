# Petscan — Su mejor detector podría tener cuatro patas

Página web del proyecto universitario de innovación en salud veterinaria que explora cómo el olfato de un perro entrenado podría ayudar a identificar señales tempranas asociadas al cáncer en Golden Retrievers.

## Contenido

- `index.html` — la página completa (secciones: problema, Golden Retriever, olfato, propuesta, entrenamiento, simulación, aplicación, desafíos, veterinario, fuentes y comentarios).
- `assets/img/` — fotografías e ilustraciones.
- `assets/fonts/` — tipografías DM Sans y Fraunces (licencia SIL OFL).
- `assets/js/` — motor de la página y React 18.3.1, incluidos localmente para que funcione sin depender de servicios externos.

## Ver la página

Es un sitio estático: no requiere instalación ni compilación.

- **En local:** desde esta carpeta ejecuta `python3 -m http.server` y abre <http://localhost:8000>.
- **En internet (GitHub Pages):** en el repositorio ve a *Settings → Pages*, elige *Deploy from a branch*, la rama `main` y la carpeta `/ (root)`. La página quedará en `https://<usuario>.github.io/<repositorio>/`.

> Nota: los comentarios del formulario se guardan solo en el navegador mientras la página está abierta; no se envían a ningún servidor.
